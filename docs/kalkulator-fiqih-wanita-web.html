Kalkulator Fiqih Wanita

Data Perhitungan

Cukup isi dua langkah pokok — jenis kasus dan fase darah — lalu tekan Hitung. Data lanjutan di bagian bawah hanya dibuka bila kasusnya memerlukan.

Langkah 1 — Jenis kasus
Langkah 2 — Fase keluarnya darah

Satu fase = satu rentang darah dengan warna yang sama. Bila darah berhenti lalu keluar lagi, buat fase terpisah — jeda bersih di antaranya terdeteksi otomatis. Warna menentukan kekuatan: Hitam (5) > Merah (4) > Coklat (3) > Kuning (2) > Keruh (1). Darah kuat (qawi) = skor ≥ 4.

Langkah 3 — Data persalinan (nifas)

Untuk kebanyakan kasus, langkah pokok di atas sudah cukup. Buka bagian ini hanya bila kasusnya memerlukan — misalnya punya kebiasaan (adat), darahnya terputus-putus dalam satu masa, atau ingin rincian qadha shalat di awal/akhir darah.
