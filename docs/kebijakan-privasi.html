Kebijakan Privasi

Terakhir diperbarui: 31 Oktober 2026. Halaman ini menjelaskan data apa yang dikumpulkan situs Kalkulator Fiqih Wanita dan bagaimana data tersebut digunakan.

Data yang kami kumpulkan

Situs ini tidak meminta akun, tidak meminta nama, alamat email, maupun nomor telepon. Situs ini juga tidak mengirim data perhitungan Anda ke server kami — semua perhitungan dilakukan di peramban (browser) perangkat Anda sendiri.

Data yang Anda masukkan — seperti fase darah, data adat, data nifas, catatan kalender, dan daftar qadha — hanya disimpan secara lokal di perangkat Anda (penyimpanan lokal peramban), agar catatan Anda tetap tersedia saat membuka situs ini kembali. Data tersebut tidak kami terima, tidak kami lihat, dan tidak kami bagikan. Anda dapat menghapusnya kapan saja dengan menghapus data situs di pengaturan peramban Anda.

Cookie

Situs ini sendiri tidak memasang cookie pelacak. Satu-satunya penyimpanan lokal yang digunakan adalah penyimpanan peramban untuk preferensi tampilan (misalnya menyembunyikan pengantar) dan catatan kalender serta qadha Anda, sebagaimana dijelaskan di atas.

Perlu diketahui, situs ini dihosting di GitHub Pages. GitHub sebagai penyedia hosting dapat mencatat informasi teknis standar (seperti alamat IP dan jenis peramban) dalam log servernya sesuai kebijakan privasi GitHub.

Iklan pihak ketiga

Saat ini situs ini belum menampilkan iklan apa pun dan belum memasang kode iklan. Bila di kemudian hari situs ini menampilkan iklan — misalnya melalui Google AdSense — pihak ketiga penyedia iklan (termasuk Google) dapat menggunakan cookie untuk menayangkan iklan berdasarkan kunjungan Anda ke situs ini dan situs lain. Pengguna dapat menonaktifkan iklan yang dipersonalisasi melalui Pengaturan Iklan Google. Halaman ini akan diperbarui bila kebijakan iklan berubah.

Perubahan kebijakan

Kebijakan privasi ini dapat diperbarui sewaktu-waktu, dan tanggal pembaruan di atas akan diubah. Bila ada pertanyaan tentang kebijakan ini, silakan hubungi pengelola melalui halaman Kontak.
